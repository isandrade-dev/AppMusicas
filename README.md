# 🎵 App Música

Projeto desenvolvido em **C#** com o objetivo de praticar conceitos de **Programação Orientada a Objetos (POO)** e criação de uma aplicação simples para gerenciamento de álbuns e músicas.

## 📌 Sobre o projeto

O **App Música** permite trabalhar com álbuns musicais e suas respectivas músicas.

O projeto possui funcionalidades para:

* 🎶 Criar um álbum;
* ➕ Adicionar músicas ao álbum;
* 📋 Exibir as músicas cadastradas;
* ⏱️ Calcular a duração total do álbum.

A classe `Album` mantém uma lista de músicas e utiliza a duração de cada música para calcular o tempo total necessário para ouvir o álbum.

## ⚙️ Funcionamento

Um álbum recebe um nome através do construtor e possui uma lista de músicas.

As músicas podem ser adicionadas utilizando o método `AdicionarMusica()`. O projeto também possui o método `ExibirMusicasDoAlbum()`, responsável por apresentar as músicas cadastradas e a duração total do álbum.
